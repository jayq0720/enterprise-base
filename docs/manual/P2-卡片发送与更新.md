# 审批卡片发送与后台更新（P2-G2，回调另交付）

前置为原生两级请假流程及卡片存储/API 底座。默认关闭；服务器 `eb_wecom_cards` 开启后还需 `desk_url` 为 HTTPS 后台根地址。每次进入主管/HR 阶段，事务内生成唯一记录，提交后才交给队列发送。重复事件和重复任务不重复发送；卡片只取姓名、假期类型、日期、天数、事由，不查询敏感员工字段。

后台审批/退回后同样将旧卡片标为完成，异步把按钮改为结果和处理人。网络失败不回滚审批，也不重做审批；最多尝试三次，小时任务补试。超过 72 小时的更新凭证标为过期，不伪报卡片已更新。时间保存为带时区 UTC 字符串，日志仅单号、动作和结果。此部分未启用公网回调；真实企业微信收发仍待部署，CI 使用合成 HTTP 和原生空库事件验证。
