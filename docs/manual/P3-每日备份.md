# 每日备份开发验收说明（P3-G2）

正式操作、age离线放置及每天北京时间03:00的systemd安装步骤统一见[部署运维手册](部署运维手册.md#每日加密备份)，本篇只保留实现和证据边界。

- 备份持有data/operations.lock，与恢复和发布串行；不删除锁文件。
- 同分区700暂存区收集数据库、文件、Qdrant快照、Caddy证书、企业微信会话和secrets；用固定版age加密，清单只在包内。
- 成功且明文清理后才按本项目日/周策略删除过期包；失败不执行保留清理。
- 应用暂停写入，结束只恢复原先运行的服务并等健康。SIGTERM/SIGINT延迟到安全边界；SIGKILL/断电后由运维核对与清理。
- 本机与CI使用真实age、进程锁、信号和Docker命令替身验证，不以这些协议测试替代业务恢复。
- 2026-10-20云端测试环境小量数据整套暂停约2分15秒；正式数据耗时须重测，不承诺固定窗口。
- 隔离恢复及正式回退分别采用make restore和受二次确认保护的make rollback，后者要求P3-G1全部前置合入。

包格式及锁定工具许可证见[备份包格式](P3-备份包格式.md)。客户服务器的定时安装、异地副本和周期演练由JQ执行，不能根据加密包生成成功勾选恢复验收。
