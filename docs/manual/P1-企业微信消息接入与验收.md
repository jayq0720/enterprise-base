# P1-G5 企业微信消息接入与验收

入口使用 `wechatcom_app`，连接 HR 助手 Chatflow（`dify_app_type=chatbot`）。在服务器密钥文件填写企业 ID、应用 Secret、Agent ID、回调 Token、EncodingAESKey 和 HR 助手应用 Key，然后按 [部署步骤](../../deploy/LOCAL.md) 启动。先按 [HR 助手部署手册](P1-HR助手部署与验收.md) 关闭 HR 助手和制度问答的网页版，保留 API 访问。应用可见范围只给授权测试员工。

## 会话配置

- `dify_conversation_max_messages=0`：关闭上游默认每五条消息清空会话的行为；否则第六条“确认请假”可能丢失草稿。
- `expires_in_seconds=0`：运行期间不按空闲时间清理会话。
- `concurrency_in_session=1`：同一员工串行处理，避免首批并发消息各自创建会话。
- `dify_error_reply` 使用固定提示，避免把内部异常作为回复。未知或离职员工的业务拒绝由 X3/X4 和 HR 助手流程完成；入口自身不查询 Frappe，不能把验签通过当成员工有权限。

上游会话映射只保存在进程内；容器重启、升级或多副本切换会丢失 `conversation_id`，`wechat_data` 卷不保存这份映射。保持单实例；维护前通知员工完成或取消请假草稿，维护后重新发起，不能直接确认旧草稿。若验收要求跨重启恢复，须由 Claude/JQ 决定修改 HR 助手草稿保存方式；本配置不实现持久化。不自动过期会增加内存占用，试运行需记录进程内存趋势。

## 可重复探针

`config/dify-on-wechat/probe.py` 从指定的未修改上游文件提取相关类/方法，用合成员工和替代 HTTP 响应验证身份传递、连续八条消息、不同员工隔离、重建进程对象后会话丢失，以及回调拒绝后不处理消息。探针只输出布尔性质的结果，不读取运行环境密钥，不连接 Dify/企业微信，不等同端到端实测。

在仓库根目录，先拉取部署已锁定的官方镜像，再离线执行：

```sh
docker pull hanfangyuan/dify-on-wechat@sha256:2ef2ecf9f081301fd34f9ceb4397f1d6cd6dac2eb42789285970a6f31752ad76
docker run --rm --network none --platform linux/amd64 --entrypoint python \
  -v "$PWD/config/dify-on-wechat:/probe:ro" \
  hanfangyuan/dify-on-wechat@sha256:2ef2ecf9f081301fd34f9ceb4397f1d6cd6dac2eb42789285970a6f31752ad76 \
  /probe/probe.py --config /probe/config.json --crypto-runtime
```

该模式使用镜像内真实 `wechatpy` 生成合成密文、验证 GET/POST 错误签名返回拒绝；HTTP 响应与消息发送仍为替代对象。无需启动现有企业微信服务、挂密钥或连接业务网络。失败时先核对镜像实际源码，不能为通过探针改上游。

源码参考锁定在 [`4685a7d`](https://github.com/hanfangyuan4396/dify-on-wechat/tree/4685a7d89aa6881c14459037bc1d1564f84a9224)：[消息 userid](https://github.com/hanfangyuan4396/dify-on-wechat/blob/4685a7d89aa6881c14459037bc1d1564f84a9224/channel/wechatcom/wechatcomapp_message.py)、[Dify 请求](https://github.com/hanfangyuan4396/dify-on-wechat/blob/4685a7d89aa6881c14459037bc1d1564f84a9224/bot/dify/dify_bot.py)、[会话策略](https://github.com/hanfangyuan4396/dify-on-wechat/blob/4685a7d89aa6881c14459037bc1d1564f84a9224/bot/dify/dify_session.py)、[串行队列](https://github.com/hanfangyuan4396/dify-on-wechat/blob/4685a7d89aa6881c14459037bc1d1564f84a9224/channel/chat_channel.py)、[回调验签](https://github.com/hanfangyuan4396/dify-on-wechat/blob/4685a7d89aa6881c14459037bc1d1564f84a9224/channel/wechatcom/wechatcomapp_channel.py)。与 [版本表](../../deploy/VERSIONS.md) 一致，不声称官方镜像与该参考提交完全相同；镜像内执行另记结果。
