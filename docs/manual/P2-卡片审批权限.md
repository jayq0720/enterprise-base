# P2-G2 卡片动作权限

此提交只提供验签后的内部动作处理器，不注册公网接口；回调分发器合并前不启用。依赖 #51 的原生请假 Workflow、#54 的卡片记录和 #55 的发送更新。

每次按可信事件的 userid 重新查唯一在职员工、启用的后台用户及角色，锁定身份、请假单和卡片，再切换为该审批人的身份执行原生 Workflow。不能批自己，不能替其他审批人处理；已完成卡片重复事件只确认完成，不再次审批。事件参数不能直接通过 REST 调用本处理器。

原生站点测试使用合成事件和模拟推送队列，覆盖两级审批、退回、重复点击、他人/未知身份/离职/过时卡片/自批拒绝及 HTTP 非白名单拒绝。企业微信真实验签、收卡、更新及离职拦截仍待部署后联测；日志仅保留单号、动作和结果。
