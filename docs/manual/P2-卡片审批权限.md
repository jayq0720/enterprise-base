# P2-G2 卡片动作权限

内部动作处理器不注册公网方法，由 [统一回调](P2-企业微信统一回调.md) 验签后调用。#51 的原生请假 Workflow、#54 的卡片记录、#55 的发送更新及 #57 的分发器均已合入；按 [部署与验收](P2-审批卡片部署与验收.md) 在测试环境启用，默认 bridge。

每次按可信事件的 userid 重新查唯一在职员工、启用的后台用户及角色，锁定身份、请假单和卡片，再切换为该审批人的身份执行原生 Workflow。不能批自己，不能替其他审批人处理；已完成卡片重复事件只确认完成，不再次审批。事件参数不能直接通过 REST 调用本处理器。

原生站点测试使用合成事件和模拟推送队列，覆盖两级审批、退回、重复点击、他人/未知身份/离职/过时卡片/自批拒绝及 HTTP 非白名单拒绝；真实 crypto 签名 HTTP 用例已在两个空库执行通过。企业微信线上收卡、审批更新及离职拦截仍待部署后联测；日志仅保留单号、动作和结果。
