# 发布与回滚控制器

`release.py` 串联main检查、独立目标校验、维护锁、加密备份、版本记录、构建、迁移和自检；命令行接线见后续正式运维手册。App镜像须有与基线提交匹配的revision标签，三项运行服务须匹配基线镜像；从当前运行checkout发起，不先手工checkout新版本。原镜像留本机缓存标签。迁移前即写数据库恢复要求，镜像准备失败不停止旧服务；开始应用切换后失败保持维护状态并提示回滚。

回滚默认选上一条未回滚记录，先校验备份和非镜像配置指纹；密钥/部署配置变化拒绝自动套用记录。需恢复数据时要求显式RESTORE_DATA=1、离线IDENTITY和交互终端两次确认，先恢复整个数据包再起旧版服务。恢复失败保持停服，成功后仍须按上线清单复核离职账号、权限和外部接口。测试使用真实Git、状态文件与锁，容器命令及数据覆盖使用替身，验证镜像准备/迁移故障、数据库标记、先恢复后启动及配置变化拒绝；完整发布回滚仍须云端演练。
