# 用户手册

适用对象：普通员工、请假审批人和入职事项负责人。应用名称、入口和联系人由公司配置；下文示例不含真实员工信息。功能须由管理员部署并开通，截图及 JQ 真机实操仍待服务器到位后补齐。

HR 支持入口：【由公司填写】。IT 支持入口：【由公司填写】。

## 进入企业助手

1. 登录本人所在公司的企业微信账号。
2. 在“工作台”找到管理员通知的企业助手应用并打开。
3. 按应用提示进入对话，不使用转发的网页版分享链接。
4. 找不到应用或打不开时，联系 IT；提示在职员工或岗位信息缺失时，联系 HR。

助手按当前企业微信账号识别本人，不能代查其他员工的个人请假数据。涉及身份证、银行卡、手机号、薪资等敏感资料，请通过公司指定的 HR 渠道办理，不发到助手对话里。

## 问制度和岗位职责

1. 直接输入问题，例如“请假需要提前多久申请？”或“我的岗位职责是什么？”。
2. 问题尽量具体；回答不完整时，在同一对话里补充要了解的事项。
3. 回答给出制度名称或出处时，先核对对应制度；无法确认或涉及例外情况时，向 HR 核实。
4. 没找到制度时，联系 HR 检查制度是否已发布、是否属于本岗位可查范围。

不同岗位能查的知识范围可能不同。助手的回答不能代替正式制度、HR 确认或审批结果。

## 查自己的假期和请假记录

1. 输入“我还有多少年假？”，查看本人可用假期信息。
2. 输入“我最近有哪些请假申请？”，查看已有申请及处理状态。
3. 若余额或记录与实际情况不符，记录发生时间和问题类型，联系 HR 核对；不要反复提交申请来修正余额。

“已发起申请”不等于“已经批准”。请假须按公司流程完成直属上级和 HR 两级处理，以系统当前结果为准。

## 发起一次请假

1. 输入请假类型、开始日期、结束日期和必要事由，例如“我要申请年假，从 YYYY-MM-DD 到 YYYY-MM-DD，事由是个人安排”，把日期替换为实际计划日期。
2. 查看助手生成的草稿，逐项核对类型、日期、天数、事由及余额提示。
3. 有误时直接重新说明要调整的内容，等助手给出新的草稿再核对。
4. 仅在确认无误后，由本人在**同一对话**中回复 **确认请假**。
5. 等待明确的提交成功提示和申请单号，再查询申请状态。
6. 如提交报错、草稿过期或无法找到草稿，先查已有申请；需要重新起草时，从第 1 步开始，避免重复起单。

起草本身不会建立正式请假单。不打算提交时不要回复确认；草稿有效时间以助手提示为准。换账号、换对话或请别人回复，不能替本人确认。HR 在起草后关闭该岗位的发起请假功能，或员工岗位失效时，确认也会被拒绝。

重复确认已有防重处理，但遇到网络超时仍应先查记录，不能只凭没有看到回复判断未提交。已发起的申请若要修改、撤销或处理退回，请联系 HR 按原单流程办理；另起一个新草稿不会修改旧单。

## 审批分配给自己的请假

1. 输入“有哪些待我审批的请假？”，查看当前分配给本人的事项。
2. 管理员已开通审批卡片时，在企业微信应用消息中打开对应卡片，核对申请人、日期、天数及事由。
3. 同意时点“通过”；需要申请人补充或修改时点“退回”。
4. 等待处理结果；直属上级通过后，申请还需 HR 处理，不能告知员工已最终批准。
5. 没有收到卡片、卡片提示已办理/权限不足或结果长时间没更新时，联系 HR 核对当前状态；按公司授权的后台入口办理。

聊天里回复“同意”不算完成审批。只能处理分给本人的事项，不能审批自己的申请，也不能通过转发卡片让别人代点。后台已经办理的申请，以系统状态为准，不反复操作旧卡片。

## 完成分给自己的入职事项

1. 从 IT 提供的 Frappe 后台入口登录；如提供企业微信扫码登录，使用本人账号完成登录。
2. 在后台搜索框输入“待办”或“ToDo”，打开待办列表。
3. 打开分给本人的入职待办，查看对应任务，并实际完成开通账号、交付设备等事项。
4. 完成后，将**自己的这条待办**状态改为“已关闭（Closed）”，点击“保存”。
5. 对应任务会自动完成；所有入职事项完成后，HR 看到的入职单才会全部完成。
6. 无法访问后台或待办、负责人有误时，联系 HR/IT；不要替另一位负责人关待办。

负责人仅能查看获授权的任务，不因此获得新员工档案、录用通知或整张入职单的访问权。后台提示 403 时，先联系 IT 检查公司允许的访问网络和账号授权，不自行申请更多角色来绕过限制。

## 遇到问题找谁

| 现象或提示 | 怎么处理 |
| --- | --- |
| “未找到你的在职员工信息” | 找 HR 核对本人企业微信账号与在职档案；不要提供别人的身份代查 |
| 员工档案没有岗位、岗位已失效 | 找 HR 补齐或修正真实岗位后再试 |
| “你的岗位没有开通……” | 找 HR 确认该功能是否应为本岗位开启 |
| 找不到制度、岗位职责为空或内容过期 | 找 HR 核对制度发布、岗位职责及知识可见范围 |
| “HR 系统暂时不可用”或一直没有回复 | 稍后再试；持续发生时找 IT，不把错误当成余额为零或审批通过 |
| 草稿过期、确认失败或网络超时 | 先查已有申请，再决定是否重新起草；仍不清楚时找 HR |
| 卡片已处理、无权限或没有收到卡片 | 找 HR 核对当前审批人和状态，再由 IT 排查入口/卡片服务 |
| 后台打不开、无法登录或看不到本人待办 | 找 IT 检查入口及账号，找 HR 检查事项分配 |

报障时只提供发生时间、功能名称和去标识的错误提示；截图遮住员工内容、真实账号和个人资料。不要转发包含密钥、完整员工档案或请假事由的运行日志。
