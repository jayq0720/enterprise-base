# 任务卡 P2-G2：X2 企业微信审批卡片

- 负责：GPT　审核：Claude　验收：JQ
- 分支：`gpt/P2-G2-wecom-cards`，目标分支 `main`
- 依赖：P1-G3 – P1-G5（企业微信应用和 userid 绑定）、P2-G1（请假审批流程）

## 要做的事

1. 请假单进入某人的审批步骤时，给审批人推企业微信模板卡片：申请人姓名、假期类型、起止日期、天数、事由，以及“通过”“退回”两个按钮。**不放手机号、余额以外的个人信息。**
2. 审批人点按钮后，企业微信回调到 X2：
   - 校验回调签名，失败一律拒绝。
   - 按回调里的 userid 找到在职员工和 Frappe 用户，用**这个人自己的权限**执行 Workflow 动作。他不是当前审批人时拒绝，不能用管理员身份代办。
   - 同一张卡片重复点击只生效一次。
3. 办完后更新卡片，显示“已通过 / 已退回”和处理人；在后台审批的单子也要把卡片更新掉。
4. 回调和推送的日志只记单号、动作和结果，不记卡片内容。

## 验收

- 在企业微信里收到卡片，点“通过”后 Frappe 里状态正确、卡片更新。
- 测试覆盖：
  - 验签失败被拒
  - 非当前审批人点按钮被拒
  - 重复点击只生效一次
  - 离职员工点按钮被拒
