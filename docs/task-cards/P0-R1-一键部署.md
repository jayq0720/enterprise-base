# 任务卡 P0-R1：一键部署

- 负责：Grok　审核：Claude　验收：JQ
- 时间：10-15 – 10-20
- 分支：`grok/P0-R1-compose`

## 要做的事

1. `deploy/docker-compose.yml`（或按组件拆成几个 compose 文件，由 `deploy/Makefile` 统一起停）：
   - Dify：用官方 `docker/docker-compose.yaml` 的服务定义，向量库改为 Qdrant（`VECTOR_STORE=qdrant`）。
   - Frappe + Frappe HR + Frappe Wiki：基于 frappe_docker，自定义镜像只装 `hrms`、`wiki` 两个 App（和以后我们自己的 `enterprise_base`）。
   - dify-on-wechat：官方镜像，配置文件挂载自 `config/dify-on-wechat/`，密钥走环境变量。
   - Caddy 统一入口：`dify.<域名>`、`hr.<域名>`、`wecom.<域名>`，域名由 `.env` 配，不写死。
2. 所有镜像锁定到具体版本号（不用 `latest`），在 `deploy/VERSIONS.md` 列版本表和许可证。
3. `deploy/.env.example`：列出所有变量，值留空或填明显的占位；真实值放 `deploy/secrets/`（已 gitignore）。
4. `deploy/LOCAL.md`：新人从零到能登录 Dify 和 Frappe 的步骤，目标 30 分钟内。
5. 数据卷全部有名字，`docker compose down && up` 后数据不丢。
